About Lab 2

The purpose of this lab is to develop a stronger understanding of basic HTML structure while learning how to create and manage multiple web pages with in a single project. This lab introduces the use of relative and absolute links, allowing pages to connect to each other as well as to external websites. By completing this lab, students practice organizing files correctly, using tables for simple navigation, and following proper naming conventions. The lab also reinforces the importance of writing clean, well-structured HTML code and helps build fondational skills that will be used in future web development and application projects.
